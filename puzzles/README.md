# Úlohy (puzzle)

Úlohy pochází z otevřené databáze [Lichess](https://database.lichess.org/#puzzles), licence CC0 1.0 (díky lichess.org).
Výběr 46 971 úloh v pásmech po 100 bodech hodnocení (400 až 2800+), převzatý z výběru projektu yarosz/light-chess (dump z 9. 9. 2026).
Každý tah všech úloh ověřený knihovnou chess.js.

Formát řádku: `id;FEN;tahy UCI;rating;motivy`. FEN je pozice před tahem soupeře, první tah zahraje soupeř, pak se střídá hráč a soupeř.
Úlohu jde otevřít na `https://lichess.org/training/<id>`.
